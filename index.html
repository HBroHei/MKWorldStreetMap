Materials / Libraries Used

Map Vectorisation

  • QGIS

    The primary GIS software used.

  • qgis2web

    The tool used to convert into web maps.

  • MKW-RoadMap

    The base map used for vectorising most of the roads and routes.

  • Mario Kart World – Nintendo Direct (Video Screenshot)

    The base satelite map used for vectorising missing roads and other geographic features (Rivers, Islands, etc).

  • Mario Kart World (Nintendo Switch 2 Game)

    The game that this map is based on, with images and location details directly from the game. Support the game by buying it!

  • Super Mario Wiki

    Information source for some details of the map.

Web App

  • OpenLayers

    The main library used to render the map.

  • GeoJSON Path Finder

    The library used for the routing function of the map.

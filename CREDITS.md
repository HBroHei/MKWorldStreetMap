## Materials / Libraries Used

### Map Vectorisation

*   #### [QGIS](https://qgis.org/)
    
    The primary GIS software used.
    
*   #### [qgis2web](https://github.com/qgis2web/qgis2web)
    
    The tool used to convert into web maps.
    
*   #### [MKW-RoadMap](https://github.com/MrL314/MKW-RoadMap)
    
    The base map used for vectorising most of the roads and routes.
    
*   #### [Mario Kart World – Nintendo Direct (Video Screenshot)](https://www.youtube.com/watch?v=3pE23YTYEZM)
    
    The base satelite map used for vectorising missing roads and other geographic features (Rivers, Islands, etc).
    
*   #### Mario Kart World (Nintendo Switch 2 Game)
    
    The game that this map is based on, with images and location details directly from the game. Support the game by buying it!
    
*   #### [Super Mario Wiki](https://mariowiki.com/)
    
    Information source for some details of the map.
    

### Web App

*   #### [OpenLayers](https://openlayers.org/)
    
    The main library used to render the map.
    
*   #### [GeoJSON Path Finder](https://github.com/perliedman/geojson-path-finder)
    
    The library used for the routing function of the map.
    

## Generative AI Usage

Generative AI is used for the following part:

*   Routing Function
*   Search function suggestions
*   Porting from script tags to NPM and ES6 modules
*   CSS Animation
*   General Debugging Helps

**NOTE: This project aims to be human-lead. 70% of the code should be written or modified by a human. Every AI-generated code are all manually reviewed by the project owner throughly before putting them into production use.**
